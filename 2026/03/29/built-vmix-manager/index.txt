1b:T568,<p>On 29 March 2026 I started <strong>vMix Manager</strong>, a Python and PyQt utility for people who run large vMix (live video production) sessions. The repo has 24 commits.</p>
<h2 id="what-it-does">What it does</h2>
<p>From the README:</p>
<ul>
<li><strong>Direct XML engine</strong>: parses and rewrites the <code>.vmix</code> file itself. Inputs keep their volume, mute, loop and position settings, and each imported or cloned input gets a new <strong>UUID</strong>.</li>
<li><strong>Batch import</strong>: queue many folders. For each one, a <strong>GT Title divider</strong> is inserted automatically, with an injected XML payload that sets a large bold font so dividers are readable on multiviewers.</li>
<li><strong>Category swap</strong>: move content between vMix category slots (1–6 and custom 50–65) by rewriting each input's <code>Category</code> attribute while keeping its order.</li>
<li><strong>Cloning and relinking</strong>: import structures from other <code>.vmix</code> files or folder trees, mark missing files, and <strong>relink</strong> all paths when a project moves to another drive.</li>
<li><strong>Housekeeping</strong>: export a category's files to a folder, three levels of wipe, drag-and-drop reordering and a timestamped activity log.</li>
</ul>
