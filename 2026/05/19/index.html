Paper summary

Paper summary: Code as Agent Harness

A survey that treats code as the infrastructure of agents, not just their output: the interface agents act through, the mechanism for planning, memory and verification, and the shared artefact that coordinates multiple agents.

  • In agent systems, code has become the medium for reasoning, acting, modelling the environment and verifying by execution.
  • The survey is organised in three layers: harness interface, harness mechanisms, and scaling to multi-agent settings.

Study

LangChain · LangGraph

LangGraph models an application as a state machine: typed state, nodes that update it, and conditional edges, used here to build a small corrective-retrieval loop that rewrites the query when retrieval looks weak.

  • A LangGraph app is a graph: nodes are functions that update a shared state, and edges (including conditional ones) decide what runs next.
  • Loops are allowed, which is what agent-style "try, check, retry" workflows need.
