Agentic AI · ReAct

ReAct interleaves reasoning ("Thought") with tool use ("Action") and results ("Observation"); the prompt format, a parser for model output, and a full trace with a scripted model.

  • ReAct = Thought → Action → Observation, repeated, so reasoning can react to what tools actually return.
  • The application parses the model's text; the model never runs anything itself.
