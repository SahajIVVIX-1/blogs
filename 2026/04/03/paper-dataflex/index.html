Paper summary: DataFlex: A Unified Framework for Data-Centric Dynamic Training of Large Language Models

DataFlex unifies dynamic data selection, domain-mixture adjustment and sample reweighting in one framework built on LLaMA-Factory, so data-centric methods can be compared fairly and dropped into normal training.

Paper card
Paper
DataFlex: A Unified Framework for Data-Centric Dynamic Training of Large Language Models (2026)
Authors
Hao Liang, Zhengyang Zhao, Mingrui Chen, Meiyi Qiang, Lu Ma, Rongyi Yu et al.
Task
Unified, reproducible data-centric LLM training
Method
Framework on LLaMA-Factory with trainer abstractions for sample selection, domain mixture and reweighting; DeepSpeed ZeRO-3 support
Data
Mistral-7B and Llama-3.2-3B (MMLU); Qwen2.5-1.5B on SlimPajama at 6B and 30B tokens
Result
Dynamic selection beats static full-data training on MMLU; DoReMi and ODM improve MMLU and perplexity over default mixtures, per the abstract
Links
arXiv · PDF

Problem

Data selection, mixture optimisation and reweighting methods are developed in isolated codebases with inconsistent interfaces, which hinders reproducibility and fair comparison.

Method

DataFlex, from the same group as DataFlow (Dec 2025 on this blog), is built on LLaMA-Factory (Mar 2024). It supports three paradigms:

  • sample selection
  • domain mixture adjustment
  • sample reweighting

It stays compatible with the normal training workflow as a drop-in replacement, and unifies shared operations (embeddings, inference, gradients), with support for DeepSpeed ZeRO-3.

Key results

From the abstract:

  • dynamic data selection consistently beats static full-data training on MMLU for Mistral-7B and Llama-3.2-3B
  • for mixtures, DoReMi and ODM improve MMLU accuracy and perplexity over default proportions when pre-training Qwen2.5-1.5B on SlimPajama at 6B and 30B tokens

Limitations

There’s no dedicated limitations section in the extracted text. It’s a framework, so its value grows with the number of methods it integrates.
