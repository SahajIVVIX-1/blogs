1b:T879,<p>On 20 April 2026, in the middle of my LangChain phase, I started <strong>Multi-Agent-RAG</strong>. The repo now has 46 commits, with a Python backend and a TypeScript frontend.</p>
<h2 id="architecture">Architecture</h2>
<p>From the README:</p>
<ul>
<li>A <strong>FastAPI gateway</strong> checks an API key, applies IP-based <strong>rate limiting</strong> (Redis), runs a <strong>prompt-injection guard</strong>, and looks up a <strong>semantic cache</strong> (Qdrant ANN, cosine ≥ 0.96) and chat history (Redis, 1-hour TTL).</li>
<li>A <strong>Supervisor</strong> LLM classifies each message into one of four routes:
<ul>
<li><strong>Retriever agent</strong>: <strong>Corrective RAG</strong> in LangGraph. An LLM grader checks the relevance of retrieved documents, and the agent rewrites the query and retrieves again, at most two times.</li>
<li><strong>DB agent</strong>: natural language to SQL, read-only, with a forbidden table.</li>
<li><strong>Tool agent</strong>: email actions under a <strong>Draft → Confirm → Execute</strong> human-in-the-loop flow, with a domain allow-list and hourly caps.</li>
<li><strong>Chat agent</strong>: plain conversation.</li>
</ul>
</li>
<li>Retrieval is <strong>hybrid</strong>: 384-dimensional dense vectors in Qdrant plus <strong>BM25</strong>, reranked by a <strong>CrossEncoder</strong> (<code>ms-marco-MiniLM-L-6-v2</code>). Small 200-token child chunks are retrieved and expanded to 800-token parent context.</li>
<li>A <strong>Validation agent</strong> re-grounds every answer before it's returned.</li>
</ul>
<h2 id="reported-quality">Reported quality</h2>
<p>The README lists <strong>RAGAS</strong> results of <strong>0.81 faithfulness</strong>, <strong>1.00 context precision</strong>, <strong>0.90 context recall</strong> and <strong>0.75 answer relevancy</strong> on its evaluation datasets.</p>
