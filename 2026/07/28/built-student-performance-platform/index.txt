20:T5c3,<p>On 28 July 2026 I committed an <strong>explainable student-performance platform</strong>. It reads almost like a summary of my whole ML phase in one repo.</p>
<h2 id="pipeline">Pipeline</h2>
<p>From the README's architecture diagram:</p>
<ol>
<li><strong>Data</strong>: UCI student dataset or a synthetic raw CSV → <strong>Pandera</strong> validation and cleaning → feature engineering with a <code>ColumnTransformer</code> → stratified train/validation/test splits.</li>
<li><strong>Model benchmark</strong>: logistic regression, decision tree, random forest, <strong>XGBoost</strong>, <strong>CatBoost</strong>, <strong>LightGBM</strong>, a PyTorch <strong>MLP</strong>, a PyTorch <strong>LSTM</strong> for temporal data, and a <strong>FLAML AutoML</strong> baseline.</li>
<li><strong>Tracking</strong>: every run logged to <strong>MLflow</strong>.</li>
<li><strong>Explainability</strong>: <strong>SHAP</strong> and <strong>LIME</strong> explanations.</li>
<li><strong>Serving</strong>: a <strong>FastAPI</strong> REST API (port 8000) and a <strong>Streamlit</strong> dashboard (port 8501).</li>
</ol>
