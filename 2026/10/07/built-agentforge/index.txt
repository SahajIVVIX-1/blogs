1d:T6d6,<p>On 7 October 2026 I started <strong>AgentForge</strong>. It has 67 commits so far, more than any of my other repos.</p>
<h2 id="how-it-works">How it works</h2>
<p>From the README, three <strong>CrewAI</strong> agents run in sequence:</p>





















<table><thead><tr><th>agent</th><th>job</th></tr></thead><tbody><tr><td><strong>Researcher</strong></td><td>searches the web and reads pages with real tools</td></tr><tr><td><strong>Analyst</strong></td><td>separates evidence from interpretation and lists gaps</td></tr><tr><td><strong>Reviewer</strong></td><td>audits the analysis, records failed checks, writes the final report</td></tr></tbody></table>
<p>The design rules the README spells out:</p>
<ul>
<li><strong>Sources are never written by the model.</strong> The <code>sources</code> list is recorded by the <code>web_search</code> and <code>fetch_page</code> tools, and each source is labelled "page read" or "search result only".</li>
<li><strong>Progress is real.</strong> The timeline is driven by events from the running crew.</li>
<li><strong>Failures are reported as failures.</strong> Errors, timeouts and missing sources end the job as <code>failed</code> with a reason.</li>
<li><strong>Async jobs</strong>: <code>POST</code> returns <code>202</code> with a job id and the UI polls for results.</li>
<li><code>fetch_page</code> only accepts public http(s) addresses, as a basic SSRF guard.</li>
</ul>
<p>Stack: React + Vite + TypeScript frontend, Python + FastAPI + CrewAI backend.</p>
