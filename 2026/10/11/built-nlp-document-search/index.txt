1f:T5c5,<p>On 11 October 2026 I committed an <strong>NLP document search engine</strong> for a college NLP course showcase, built with Gradio (and set up for Hugging Face Spaces).</p>
<h2 id="features">Features</h2>
<p>From the README:</p>
<ul>
<li>upload <code>.txt</code> and <code>.pdf</code> documents (parsed with <strong>PyMuPDF</strong>), or use the 8 preloaded sample documents</li>
<li>an NLTK pipeline (tokenisation, normalisation, stop-word removal, Porter stemming) with a step-by-step inspector</li>
<li>a <strong>TF-IDF vector space model</strong> with smoothed IDF and L2 normalisation, ranked by <strong>cosine similarity</strong>, top-K configurable</li>
<li><strong>term-level explainability</strong>: which terms drove each ranking</li>
<li>a comparison mode between <strong>TF-IDF</strong> and plain <strong>lexical matching</strong></li>
<li>corpus analytics, SHA-256 de-duplication, a query history log, and error handling for empty queries, scanned PDFs and out-of-vocabulary terms</li>
</ul>
<p>The README also discusses the theoretical limits of lexical search, and dense embeddings and hybrid search as future work.</p>
