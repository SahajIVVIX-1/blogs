<p><strong>Transformers v5.0.0</strong> was released.</p>
<h2 id="the-technical-details">The technical details</h2>
<p>From the release notes:</p>
<ul>
<li>the <strong>first major release in five years</strong>, with <strong>1,200 commits</strong> since the last minor release</li>
<li>removes many <strong>long-due deprecations</strong>, and refactors to simplify the APIs and internals</li>
<li>significant API changes around <strong>dynamic weight loading</strong> and <strong>tokenization</strong></li>
<li>a continuously updated <strong>migration guide</strong></li>
<li>release cadence changes to <strong>weekly minor releases</strong> (v5.1, v5.2, …) so new models are available sooner</li>
</ul>

Models now print a load report too.
