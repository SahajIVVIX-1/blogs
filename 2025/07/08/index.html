Paper summary: MemOS: A Memory OS for AI System

MemOS proposes a memory operating system for LLMs that manages plaintext, activation-based and parameter-level memory as one schedulable resource, built around "MemCube" units with provenance and versioning.

  • RAG adds knowledge as plain text but is stateless; MemOS treats memory as a managed resource with a lifecycle.
  • A MemCube bundles memory content with metadata like provenance and version, and can move between memory types.
