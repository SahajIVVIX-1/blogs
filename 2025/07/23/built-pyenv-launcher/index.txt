1b:T6ac,<p>On 23 July 2025 I made the first commit of <strong>PyEnv Launcher</strong>, a desktop GUI that pulls the everyday Python workflow into one window. The repo has 13 commits and is written in Python.</p>
<h2 id="what-it-does">What it does</h2>
<p>According to the project README:</p>
<ul>
<li><strong>Projects</strong>: set a project folder, reopen recent ones, and create a standard layout (<code>data</code>, <code>notebooks</code>, <code>src</code>, <code>.gitignore</code>) in one click.</li>
<li><strong>Environments</strong>: automatically finds <strong>venv</strong> and <strong>Conda</strong> environments, shows each one's Python version and creation date, creates or deletes them, and opens a terminal with the selected environment already activated. It can also launch Jupyter inside an environment.</li>
<li><strong>Packages</strong>: lists installed packages, checks for outdated ones with <code>pip</code>, and upgrades or uninstalls them. It can freeze to <code>requirements.txt</code> or export to <code>packages.json</code>, and install from either.</li>
<li><strong>Git</strong>: shows the current branch and whether the tree is clean or dirty, with Pull and Commit actions.</li>
<li><strong>Build tools</strong>: Poetry and PDM buttons appear only when a <code>pyproject.toml</code> exists.</li>
<li><strong>UI</strong>: dark and light themes, a two-column layout and an activity log of every command's output.</li>
</ul>
<p>A standalone Windows installer is linked from the README.</p>
