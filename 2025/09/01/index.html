Paper summary: A.S.E: A Repository-Level Benchmark for Evaluating Security in AI-Generated Code

A.S.E is a repository-level benchmark for the security of AI-generated code; it finds that current LLMs still struggle with secure coding, and that a bigger reasoning budget doesn't reliably help.

  • Snippet-level benchmarks miss what happens when generated code has to fit into a real repository.
  • A larger reasoning budget did not necessarily produce more secure code.
