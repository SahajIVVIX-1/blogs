Paper summary

Paper summary: Qwen3-Omni Technical Report

Qwen3-Omni is a single model across text, image, audio and video that's reported to match same-sized single-modal Qwen models, with a Thinker–Talker MoE design and 234 ms theoretical first-packet speech latency.

  • Adding all modalities to one model didn't cost performance on any single modality, per the authors.
  • A lightweight causal ConvNet replaces block-wise diffusion for speech, so audio can stream from the first codec frame.

Computer Vision · Data augmentation

Label-preserving random transforms (flips, crops, rotation, colour jitter) with torchvision.transforms.v2, applied consistently to images and boxes.

  • Augmentation creates new training views of the same image so the model learns invariances instead of memorising pixels.
  • Every augmentation must keep the label true; a flipped "6" might become a "9".

Built this: SIH-AI-Gyani microplastic detector

A YOLO11 object detector trained to find and classify six types of microplastic polymers in images, built in a single notebook with Ultralytics.
