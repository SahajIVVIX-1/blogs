Transformers · Hugging Face Transformers: fine-tuning

Fine-tuning a small pretrained encoder (BERT-mini) for sentiment on Rotten Tomatoes with a plain PyTorch loop, and an honest comparison with the TF-IDF baseline from my NLP phase.

  • Fine-tuning reuses everything the model learned in pre-training and only has to learn the new head and small adjustments.
  • An 11M-parameter BERT-mini only tied the TF-IDF baseline here: model size matters, and strong classical baselines are hard to beat on short texts.

Paper summary: DataFlow: An LLM-Driven Framework for Unified Data Preparation and Workflow Automation in the Era of Data-Centric AI

DataFlow is an LLM-driven framework for building data-preparation pipelines from about 200 reusable operators with a PyTorch-style API, plus an agent that turns plain-language specs into pipelines.

  • Data preparation gets the same modular, composable treatment that PyTorch gave model building.
  • A 10K-sample dataset made with DataFlow let base models beat counterparts trained on 1M Infinity-Instruct samples, per the authors.
