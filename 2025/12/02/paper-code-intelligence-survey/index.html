Paper summary: From Code Foundation Models to Agents and Applications: A Comprehensive Survey and Practical Guide to Code Intelligence

A large survey and practical guide to code LLMs, from data curation and pre-training through SFT, RL and coding agents, comparing general and code-specialised models and the gap between benchmarks and real development.

📄 RESEARCH PAPER CARD
Paper
From Code Foundation Models to Agents and Applications: A Comprehensive Survey and Practical Guide to Code Intelligence (2025)
Authors
Jian Yang, Xianglong Liu, Weifeng Lv, Ken Deng, Shawn Guo, Lin Jing et al.
Task
Synthesising the code-LLM field
Method
Survey plus analytic and probing experiments across the model life cycle
Dataset
General LLMs (GPT-4, Claude, LLaMA) and code LLMs (StarCoder, Code LLaMA, DeepSeek-Coder, QwenCoder)
Key Result
A practical guide and an analysis of the research–practice gap
Links
arXiv Page ↗PDF Full Text ↗

Problem

Code LLMs moved from rule-based systems to Transformers, and from single-digit to over 95% success on benchmarks like HumanEval, powering tools like GitHub Copilot, Cursor and Claude Code. But the field is scattered, and benchmark success doesn’t equal real-world usefulness.

Method

A comprehensive synthesis and practical guide, with the authors’ own analytic and probing experiments, covering the full life cycle:

  • data curation and code pre-training
  • supervised fine-tuning and reinforcement learning
  • prompting paradigms
  • autonomous coding agents

It compares general LLMs (GPT-4, Claude, LLaMA) with code-specialised ones (StarCoder, Code LLaMA, DeepSeek-Coder, QwenCoder).

Key results

Beyond the synthesis, the survey articulates a research–practice gap: academic benchmarks versus real development needs, such as correctness, security (see A.S.E from September), awareness of large codebases, and integration with developer workflows.

Limitations

As a survey, it reflects the state of the field at the time of writing.
