    Paper summary: OpenCoder: The Open Cookbook for Top-Tier Code Large Language Models

    OpenCoder is a top-tier code LLM released as an "open cookbook": weights and inference code plus reproducible training data, the full data-processing pipeline and training protocols.

  • 19 Sept 2024 · Paper summary

    Paper summary: Qwen2.5-Coder Technical Report

    Qwen2.5-Coder is a family of six code models (0.5B to 32B) continued-pretrained on over 5.5 trillion tokens, reported to set state-of-the-art results on more than 10 code benchmarks for their sizes.

  • 30 Oct 2023 · Paper summary

    Paper summary: CodeFusion: A Pre-trained Diffusion Model for Code Generation

    CodeFusion generates code with a diffusion model that iteratively denoises a whole program conditioned on the natural-language request, instead of writing tokens left to right.
