    Agentic AI · Model Context Protocol (MCP)

    MCP standardises how applications expose tools, resources and prompts to LLM clients; an MCP server built with the official Python SDK and queried from an in-process client.

    Structured tool calling with a real local model: Python functions become JSON schemas, Qwen2.5-0.5B-Instruct emits tool calls through its chat template, and the app parses and executes them, including one wrong call.

  • 23 Dec 2025 · Paper summary

    Paper summary: DataFlow: An LLM-Driven Framework for Unified Data Preparation and Workflow Automation in the Era of Data-Centric AI

    DataFlow is an LLM-driven framework for building data-preparation pipelines from about 200 reusable operators with a PyTorch-style API, plus an agent that turns plain-language specs into pipelines.

  • 29 Jul 2025 · Paper summary

    Paper summary: Agentic Reinforced Policy Optimization

    ARPO is an RL algorithm for multi-turn tool-using agents that samples extra rollouts right after tool calls, where the model's token entropy spikes, and is reported to beat trajectory-level RL with half the tool calls.

  • 7 Mar 2025 · Paper summary

    Paper summary: START: Self-taught Reasoner with Tools

    START teaches a long chain-of-thought reasoning model to call a Python interpreter mid-reasoning, using inserted hints ("Wait, maybe using Python here is a good idea") and rejection-sampling fine-tuning.

  • 25 Nov 2024 · AI updates

    Anthropic open-sources the Model Context Protocol (MCP)

    Anthropic open-sourced the Model Context Protocol, an open standard for connecting AI assistants to data sources and tools through MCP servers and clients, with a specification, SDKs, local server support in Claude Desktop and pre-built servers.

  • 21 Mar 2024 · Paper summary

    Paper summary: LlamaFactory: Unified Efficient Fine-Tuning of 100+ Language Models

    LlamaFactory is an open framework that brings many efficient fine-tuning methods together for 100+ LLMs, including a no-code web UI called LlamaBoard.
