    Sentence embeddings for semantic search: mean-pooling a small encoder (all-MiniLM-L6-v2), cosine similarity, and finding the most relevant sentence for a query without any shared keywords.

    Paper summary: General Agentic Memory Via Deep Research

    General Agentic Memory keeps a light memory plus the full history in a page-store, then uses a "researcher" agent to build the right context at request time, like just-in-time compilation for memory.

    Google released EmbeddingGemma, a 308M-parameter embedding model with a 2K context supporting 100+ languages; at release it was the top text-only multilingual model under 500M on MTEB.
