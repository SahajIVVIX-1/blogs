About This Engineering Notebook

This site is my public engineering journal, starting on 4 August 2023 (my first day at PDEU) and updated continuously. It serves as both a structured learning handbook and an archival log across three primary tracks:

Study Guides

Structured Technical Notes

Sequential, topic-by-topic curriculum notes across 15 engineering phases. Every code snippet is executed in a controlled Python/C++ environment prior to publishing.

Paper Digests

Frontier Research Breakdowns

Rigorous breakdowns of breakthrough papers from arXiv and Hugging Face Daily Papers, cataloging mathematical formulations, benchmarks, and architectures.

AI Updates

Industry Releases

Concise, factual summaries of foundation model releases, technical reports, and major library milestones directly from official engineering blogs and model cards.

Engineering Philosophy

  • Verified Sources: Every single article explicitly cites primary sources (arXiv DOIs, GitHub repos, official release announcements).
  • Mathematical Rigor: Core concepts are explained with complete LaTeX derivations rather than hand-waving analogies.
  • Executable Implementations: Algorithms include complete, self-contained Python / PyTorch code blocks with verified outputs.
