Paper summary: Vision Transformers Need Registers

ViTs repurpose some background patch tokens as internal scratch space, which produces high-norm artifacts; adding a few extra "register" tokens fixes this and smooths attention maps.

  • Large ViTs quietly reuse uninformative background patches for internal computation, which shows up as high-norm outlier tokens.
  • Giving the model dedicated extra tokens (registers) removes the artifacts.
