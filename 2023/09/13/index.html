Python · Functions: arguments and return values

Defining functions, positional vs keyword arguments, default values, the mutable-default trap, and returning several values.

  • Default values are evaluated once, when the function is defined, so never use a mutable default like [].
  • Returning a, b actually returns one tuple, which the caller can unpack.

Würstchen: diffusion in a 42× compressed latent space

Würstchen is a text-to-image diffusion model whose text-conditional stage works in a latent space compressed 42× spatially, making training and inference much cheaper than Stable Diffusion.

  • Common latent diffusion compresses images 4–8× spatially; Würstchen reaches 42× with a two-stage decoder.
  • The announcement reports 9,000 GPU hours for v1, against 150,000 for Stable Diffusion 1.4.
