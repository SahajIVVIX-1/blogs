1f:T59b,<h2 id="what-happened">What happened</h2>
<p><strong>Transformers v4.35.0</strong> switched to <strong>safetensors</strong> as the default way to save models and added several new models.</p>
<h2 id="the-technical-details">The technical details</h2>
<p>From the release notes:</p>
<ul>
<li><strong>Distil-Whisper</strong>: a distilled Whisper that's <strong>6× faster</strong>, <strong>49% smaller</strong>, and within <strong>1% word error rate</strong> on out-of-distribution data. It copies Whisper's entire <strong>encoder</strong>, keeping its robustness, but only <strong>2 decoder layers</strong>, which speeds up token-by-token generation. It's MIT licensed, with Flash Attention 2 and speculative decoding support.</li>
<li><strong>Fuyu-8B</strong> (from Adept): a <strong>decoder-only</strong> multimodal model. A linear layer embeds image patches, which are then treated <strong>like text tokens</strong>, with a special image-newline token marking row ends.</li>
<li>Also added: Kosmos-2, SeamlessM4T and Owl-v2.</li>
</ul>
<h2 id="why-it-matters">Why it matters</h2>
<p>The safetensors docs describe the format as a safe alternative to pickle-based checkpoints, which can execute code when loaded. Making it the default is a security improvement for everyone downloading models.
