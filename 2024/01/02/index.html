Paper summary: DocLLM: A layout-aware generative language model for multimodal document understanding

DocLLM adds layout awareness to an LLM using only text bounding boxes, with no image encoder, via disentangled text/layout attention and a text-infilling pre-training objective.

  • Instead of a vision encoder, DocLLM feeds each token's bounding box and splits attention into text and spatial parts.
  • The infilling objective helps with the irregular layouts of forms and invoices.
