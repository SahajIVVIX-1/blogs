Machine Learning · Ordinary Least Squares: Geometric Orthogonal Projection & Derivation

An exhaustive first-principles derivation of Ordinary Least Squares regression: column space geometry, the hat matrix projection, SVD pseudo-inverse, condition number hazards, and verified runnable Python.

1. Academic & Historical Context

Ordinary Least Squares (OLS) is the foundational cornerstone of statistical learning and predictive modeling. Formally introduced by Adrien-Marie Legendre (1805) in his work Nouvelles méthodes pour la détermination des orbites des comètes and rigorously linked to probability theory by Carl Friedrich Gauss (1809) in Theoria Motus Corporum Coelestium, linear regression established the first mathematically closed-form parameter estimation technique for empirical data.

Under the Gauss-Markov Theorem, the OLS estimator is proved to be the BLUE (Best Linear Unbiased Estimator): among all linear unbiased estimators, OLS achieves the minimum sampling variance, requiring no distributional assumptions on the error term other than zero mean, homoscedasticity, and uncorrelated residuals.

Var⁡(w^OLS)≤Var⁡(w~),∀ linear unbiased w~\operatorname{Var}(\hat{\mathbf{w}}_{\text{OLS}}) \le \operatorname{Var}(\tilde{\mathbf{w}}), \quad \forall \text{ linear unbiased } \tilde{\mathbf{w}}Var(w^OLS​)≤Var(w~),∀ linear unbiased w~

2. Geometric Intuition: The Column Space Projection

Consider a dataset containing nnn observations and ddd features, arranged in a design matrix X∈Rn×dX \in \mathbb{R}^{n \times d}X∈Rn×d, with an observed target vector y∈Rn\mathbf{y} \in \mathbb{R}^ny∈Rn. In general, the number of observations far exceeds the number of parameters (n≫dn \gg dn≫d).

Consequently, the linear system Xw=yX\mathbf{w} = \mathbf{y}Xw=y is overdetermined: there is almost never an exact linear combination of the columns of XXX that equals y\mathbf{y}y, because y\mathbf{y}y lies outside the column space C(X)⊂Rn\mathcal{C}(X) \subset \mathbb{R}^nC(X)⊂Rn.

The fundamental goal of Ordinary Least Squares is to find the vector y^∈C(X)\hat{\mathbf{y}} \in \mathcal{C}(X)y^​∈C(X) that is closest in Euclidean distance to y\mathbf{y}y.

By the Hilbert Projection Theorem, the minimum Euclidean distance between a point and a linear subspace is achieved if and only if the line segment connecting them is perpendicular (orthogonal) to every single vector lying within the subspace:

e=(y−y^)⊥C(X)\mathbf{e} = (\mathbf{y} - \hat{\mathbf{y}}) \perp \mathcal{C}(X)e=(y−y^​)⊥C(X)

Since the columns of X=[x1,x2,…,xd]X = [\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_d]X=[x1​,x2​,…,xd​] form a basis that spans C(X)\mathcal{C}(X)C(X), the error vector e\mathbf{e}e must be orthogonal to each column xj\mathbf{x}_jxj​:

xj⊤(y−Xw∗)=0,∀j∈{1,2,…,d}\mathbf{x}_j^\top (\mathbf{y} - X\mathbf{w}^*) = 0, \quad \forall j \in \{1, 2, \dots, d\}xj⊤​(y−Xw∗)=0,∀j∈{1,2,…,d}

Stacking these ddd inner-product equations into matrix notation yields the celebrated Normal Equations:

X⊤(y−Xw∗)=0  ⟹  X⊤Xw∗=X⊤yX^\top (\mathbf{y} - X\mathbf{w}^*) = \mathbf{0} \implies X^\top X \mathbf{w}^* = X^\top \mathbf{y}X⊤(y−Xw∗)=0⟹X⊤Xw∗=X⊤y

3. Mathematical Derivation via Matrix Calculus

Let us derive the exact same result algebraically by framing OLS as an unconstrained continuous optimization problem. We seek a parameter vector w∈Rd\mathbf{w} \in \mathbb{R}^dw∈Rd that minimizes the Residual Sum of Squares (RSS), defined as the squared Euclidean L2L_2L2​-norm of the error:

J(w)=12n∥y−Xw∥22=12n(y−Xw)⊤(y−Xw)J(\mathbf{w}) = \frac{1}{2n} \|\mathbf{y} - X\mathbf{w}\|_2^2 = \frac{1}{2n} (\mathbf{y} - X\mathbf{w})^\top (\mathbf{y} - X\mathbf{w})J(w)=2n1​∥y−Xw∥22​=2n1​(y−Xw)⊤(y−Xw)

Expanding the matrix quadratic product:

J(w)=12n(y⊤y−y⊤Xw−w⊤X⊤y+w⊤X⊤Xw)J(\mathbf{w}) = \frac{1}{2n} \left( \mathbf{y}^\top \mathbf{y} - \mathbf{y}^\top X\mathbf{w} - \mathbf{w}^\top X^\top \mathbf{y} + \mathbf{w}^\top X^\top X \mathbf{w} \right)J(w)=2n1​(y⊤y−y⊤Xw−w⊤X⊤y+w⊤X⊤Xw)

Noting that the scalar transpose identity y⊤Xw=(y⊤Xw)⊤=w⊤X⊤y\mathbf{y}^\top X\mathbf{w} = (\mathbf{y}^\top X\mathbf{w})^\top = \mathbf{w}^\top X^\top \mathbf{y}y⊤Xw=(y⊤Xw)⊤=w⊤X⊤y holds:

J(w)=12n(y⊤y−2w⊤X⊤y+w⊤(X⊤X)w)J(\mathbf{w}) = \frac{1}{2n} \left( \mathbf{y}^\top \mathbf{y} - 2 \mathbf{w}^\top X^\top \mathbf{y} + \mathbf{w}^\top (X^\top X) \mathbf{w} \right)J(w)=2n1​(y⊤y−2w⊤X⊤y+w⊤(X⊤X)w)

First-Order Necessary Condition: Setting Gradient to Zero

Using the standard matrix derivative identities ∇w(w⊤a)=a\nabla_{\mathbf{w}} (\mathbf{w}^\top \mathbf{a}) = \mathbf{a}∇w​(w⊤a)=a and ∇w(w⊤Aw)=(A+A⊤)w=2Aw\nabla_{\mathbf{w}} (\mathbf{w}^\top A \mathbf{w}) = (A + A^\top)\mathbf{w} = 2A\mathbf{w}∇w​(w⊤Aw)=(A+A⊤)w=2Aw (for symmetric A=X⊤XA = X^\top XA=X⊤X):

∇wJ(w)=1n(−X⊤y+X⊤Xw)\nabla_{\mathbf{w}} J(\mathbf{w}) = \frac{1}{n} \left( -X^\top \mathbf{y} + X^\top X \mathbf{w} \right)∇w​J(w)=n1​(−X⊤y+X⊤Xw)

Setting the gradient to the zero vector ∇wJ(w∗)=0\nabla_{\mathbf{w}} J(\mathbf{w}^*) = \mathbf{0}∇w​J(w∗)=0:

X⊤Xw∗=X⊤yX^\top X \mathbf{w}^* = X^\top \mathbf{y}X⊤Xw∗=X⊤y

If the matrix XXX has full column rank (rank⁡(X)=d\operatorname{rank}(X) = drank(X)=d), the Gram matrix X⊤X∈Rd×dX^\top X \in \mathbb{R}^{d \times d}X⊤X∈Rd×d is non-singular and invertible:

w∗=(X⊤X)−1X⊤y\mathbf{w}^* = (X^\top X)^{-1} X^\top \mathbf{y}w∗=(X⊤X)−1X⊤y

Second-Order Sufficient Condition: Strict Convexity

To guarantee that w∗\mathbf{w}^*w∗ is a global minimum rather than a maximum or saddle point, we evaluate the Hessian matrix:

H=∇w2J(w)=1nX⊤X\mathbf{H} = \nabla^2_{\mathbf{w}} J(\mathbf{w}) = \frac{1}{n} X^\top XH=∇w2​J(w)=n1​X⊤X

For any non-zero vector v∈Rd\mathbf{v} \in \mathbb{R}^dv∈Rd:

v⊤Hv=1nv⊤(X⊤X)v=1n(Xv)⊤(Xv)=1n∥Xv∥22≥0\mathbf{v}^\top \mathbf{H} \mathbf{v} = \frac{1}{n} \mathbf{v}^\top (X^\top X) \mathbf{v} = \frac{1}{n} (X\mathbf{v})^\top (X\mathbf{v}) = \frac{1}{n} \|X\mathbf{v}\|_2^2 \ge 0v⊤Hv=n1​v⊤(X⊤X)v=n1​(Xv)⊤(Xv)=n1​∥Xv∥22​≥0

Because XXX has full column rank, Xv=0X\mathbf{v} = \mathbf{0}Xv=0 if and only if v=0\mathbf{v} = \mathbf{0}v=0. Thus, v⊤Hv>0\mathbf{v}^\top \mathbf{H} \mathbf{v} > 0v⊤Hv>0 for all v≠0\mathbf{v} \ne \mathbf{0}v=0. The Hessian is strictly positive definite (H≻0\mathbf{H} \succ 0H≻0), establishing that J(w)J(\mathbf{w})J(w) is strictly convex and possesses a unique global minimum.

4. The Hat Matrix & Orthogonal Projection Properties

Substituting the optimal weights w∗\mathbf{w}^*w∗ back into the linear predictor yields the fitted target values y^\hat{\mathbf{y}}y^​:

y^=Xw∗=X(X⊤X)−1X⊤y=Hy\hat{\mathbf{y}} = X\mathbf{w}^* = X(X^\top X)^{-1}X^\top \mathbf{y} = H\mathbf{y}y^​=Xw∗=X(X⊤X)−1X⊤y=Hy

The operator H=X(X⊤X)−1X⊤∈Rn×nH = X(X^\top X)^{-1}X^\top \in \mathbb{R}^{n \times n}H=X(X⊤X)−1X⊤∈Rn×n is called the Hat Matrix because it “puts the hat on y\mathbf{y}y”. HHH satisfies two crucial algebraic properties of an orthogonal projection matrix:

  1. Symmetric: H⊤=(X(X⊤X)−1X⊤)⊤=X((X⊤X)−1)⊤X⊤=X(X⊤X)−1X⊤=HH^\top = \left( X(X^\top X)^{-1} X^\top \right)^\top = X \left((X^\top X)^{-1}\right)^\top X^\top = X(X^\top X)^{-1} X^\top = HH⊤=(X(X⊤X)−1X⊤)⊤=X((X⊤X)−1)⊤X⊤=X(X⊤X)−1X⊤=H
  2. Idempotent (Projecting an already-projected vector changes nothing): H2=H⋅H=X(X⊤X)−1X⊤X(X⊤X)−1X⊤=X(X⊤X)−1X⊤=HH^2 = H \cdot H = X(X^\top X)^{-1} X^\top X(X^\top X)^{-1} X^\top = X (X^\top X)^{-1} X^\top = HH2=H⋅H=X(X⊤X)−1X⊤X(X⊤X)−1X⊤=X(X⊤X)−1X⊤=H

The residual vector e\mathbf{e}e is computed using the complementary projection matrix (I−H)(I - H)(I−H):

e=y−y^=(I−H)y\mathbf{e} = \mathbf{y} - \hat{\mathbf{y}} = (I - H)\mathbf{y}e=y−y^​=(I−H)y

Notice that (I−H)(I - H)(I−H) is also symmetric and idempotent, and projects any vector onto the orthogonal complement of the column space: C(X)⊥\mathcal{C}(X)^\perpC(X)⊥.

5. Computational Complexity & Numerical Stability Hazards

While (X⊤X)−1X⊤y(X^\top X)^{-1} X^\top \mathbf{y}(X⊤X)−1X⊤y is theoretically elegant, computing (X⊤X)−1(X^\top X)^{-1}(X⊤X)−1 directly in production code is a severe numerical anti-pattern for two primary reasons:

1. Condition Number Squaring

The condition number κ(A)=∥A∥∥A−1∥\kappa(A) = \|A\| \|A^{-1}\|κ(A)=∥A∥∥A−1∥ measures how sensitive a linear system solution is to numerical rounding errors. A key matrix property dictates that:

κ(X⊤X)=(κ(X))2\kappa(X^\top X) = \left( \kappa(X) \right)^2κ(X⊤X)=(κ(X))2

If the design matrix XXX has a condition number of 10410^4104 (moderately collinear features), the Gram matrix X⊤XX^\top XX⊤X has a condition number of 10810^8108. In IEEE 754 64-bit floating point arithmetic (which offers ~16 digits of precision), half of the precision digits are completely lost to numerical noise during explicit matrix inversion.

2. Algorithmic Alternatives (QR & SVD)

Production-grade implementations (such as scikit-learn and LAPACK dgelsd) avoid forming X⊤XX^\top XX⊤X entirely:

6. Runnable Python Implementation & Numerical Proof

The following script verifies the mathematical equivalence between:

  1. Analytical Normal Equations
  2. QR Factorization
  3. SVD Pseudoinverse
  4. Scikit-Learn LinearRegression
import numpy as np
from sklearn.datasets import load_diabetes
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score
from sklearn.model_selection import train_test_split

# 1. Ingestion: Load diabetes dataset (442 samples, 10 physiological features)
X_raw, y = load_diabetes(return_X_y=True)
n_samples, n_features = X_raw.shape

# Train/Test Split (75% train, 25% test)
X_train, X_test, y_train, y_test = train_test_split(
    X_raw, y, test_size=0.25, random_state=42
)

# Prepend column of ones to design matrix for bias term: X_tilde = [1 | X]
X_bias_train = np.c_[np.ones(len(X_train)), X_train]
X_bias_test = np.c_[np.ones(len(X_test)), X_test]

# Method A: Scikit-Learn Reference
sk_model = LinearRegression(fit_intercept=True).fit(X_train, y_train)
w_sklearn = np.r_[sk_model.intercept_, sk_model.coef_]

# Method B: Direct Normal Equation via Matrix Inversion: w = (X^T X)^(-1) X^T y
w_normal = np.linalg.inv(X_bias_train.T @ X_bias_train) @ X_bias_train.T @ y_train

# Method C: QR Decomposition: X = Q R => R w = Q^T y
Q, R = np.linalg.qr(X_bias_train)
w_qr = np.linalg.solve(R, Q.T @ y_train)

# Method D: Singular Value Decomposition (SVD): X = U S V^T => w = V S^+ U^T y
U, S, Vt = np.linalg.svd(X_bias_train, full_matrices=False)
S_pinv = np.diag(np.where(S > 1e-12, 1.0 / S, 0.0))
w_svd = Vt.T @ S_pinv @ (U.T @ y_train)

# Evaluate Test Performance
y_pred = X_bias_test @ w_svd
rmse = np.sqrt(mean_squared_error(y_test, y_pred))
r2 = r2_score(y_test, y_pred)

# Matrix Condition Numbers
cond_X = np.linalg.cond(X_bias_train)
cond_XTX = np.linalg.cond(X_bias_train.T @ X_bias_train)

print(f"Condition Number kappa(X)     : {cond_X:.4f}")
print(f"Condition Number kappa(X^T X) : {cond_XTX:.4f} (Notice kappa^2 scaling!)")
print(f"Test RMSE                     : {rmse:.4f}")
print(f"Test R^2 Score                : {r2:.4f}")
print(f"Normal Eq matches Sklearn     : {np.allclose(w_normal, w_sklearn, atol=1e-8)}")
print(f"QR matches Sklearn            : {np.allclose(w_qr, w_sklearn, atol=1e-8)}")
print(f"SVD matches Sklearn           : {np.allclose(w_svd, w_sklearn, atol=1e-8)}")
print(f"Top 3 influential weights     : {np.argsort(np.abs(w_svd[1:]))[-3:][::-1] + 1}")

7. Assumptions, Diagnostics & Failure Modes

OLS guarantees unbiasedness and optimality only when key structural assumptions hold:

  1. Strict Exogeneity (E[ϵ∣X]=0\mathbb{E}[\boldsymbol{\epsilon} | X] = \mathbf{0}E[ϵ∣X]=0): The error term has zero conditional expectation given the regressors. Violations occur when relevant variables are omitted (omitted variable bias) or reverse causality exists.
  2. No Multicollinearity (rank⁡(X)=d\operatorname{rank}(X) = drank(X)=d): If two or more features are collinear, X⊤XX^\top XX⊤X becomes singular. Even near-multicollinearity inflates the standard error of regression weights: Var⁡(w^j)=σ2(1−Rj2)∑i=1n(xij−xˉj)2=σ2⋅VIF⁡j\operatorname{Var}(\hat{w}_j) = \frac{\sigma^2}{(1 - R_j^2) \sum_{i=1}^n (x_{ij} - \bar{x}_j)^2} = \sigma^2 \cdot \operatorname{VIF}_jVar(w^j​)=(1−Rj2​)∑i=1n​(xij​−xˉj​)2σ2​=σ2⋅VIFj​ Where VIF⁡j\operatorname{VIF}_jVIFj​ is the Variance Inflation Factor. When VIF⁡>5\operatorname{VIF} > 5VIF>5, parameter variance explodes, necessitating Ridge (L2L_2L2​) Regularization.
  3. Homoscedasticity (Var⁡(ϵ∣X)=σ2In\operatorname{Var}(\boldsymbol{\epsilon} | X) = \sigma^2 I_nVar(ϵ∣X)=σ2In​): If residual variance changes across feature ranges (heteroscedasticity), OLS remains unbiased but loses efficiency; standard errors become invalid, requiring White’s heteroscedasticity-consistent covariance matrix estimators.
  4. Vulnerability to Outliers & Leverage Points: Because OLS squares errors, a single extreme outlier with high leverage (hii=Hii≫2dnh_{ii} = H_{ii} \gg \frac{2d}{n}hii​=Hii​≫n2d​) can disproportionately tilt the entire fitted hyperplane. Cook’s Distance is used to identify these destructive points: Di=∑j=1n(y^j−y^j(i))2d⋅s2=ei2d⋅s2[hii(1−hii)2]D_i = \frac{\sum_{j=1}^n (\hat{y}_j - \hat{y}_{j(i)})^2}{d \cdot s^2} = \frac{e_i^2}{d \cdot s^2} \left[ \frac{h_{ii}}{(1 - h_{ii})^2} \right]Di​=d⋅s2∑j=1n​(y^​j​−y^​j(i)​)2​=d⋅s2ei2​​[(1−hii​)2hii​​]

8. Summary Checklist for Engineering Practice

  • Subspace Perspective: Recognize that fitting OLS is geometrically finding the shadow of target y\mathbf{y}y cast on the hyper-plane spanned by the feature columns.
  • Inversion Caution: Never compute inv(X.T @ X) in numerical code. Prefer SVD (np.linalg.lstsq / LAPACK dgelsd) or QR decomposition.
  • Collinearity Audit: Check condition numbers and VIF before interpreting regression coefficients as causal feature importances.
  • Residual Inspection: Always plot residuals against fitted values to detect non-linear curvature or heteroscedastic fan shapes.
