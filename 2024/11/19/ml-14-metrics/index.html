Machine Learning · Model evaluation metrics

Confusion matrix, accuracy and why it fails on imbalanced data, precision, recall, F1, ROC-AUC, and regression metrics.

Classification, starting from the confusion matrix (TP, FP, FN, TN):

metricformulaanswers
accuracy(TP+TN)/allhow often am I right? (misleading when classes are imbalanced)
precisionTP/(TP+FP)of the cases I flagged, how many were real?
recallTP/(TP+FN)of the real cases, how many did I catch?
F1harmonic mean of P and Rone balanced number
ROC-AUCarea under the TPR–FPR curveranking quality across all thresholds

Regression: MAE, RMSE (punishes big errors), R².

The demo is a heavily imbalanced problem (about 1.5% positives). A “model” that always says “negative” scores about 98.5% accuracy and catches nothing.

import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report, roc_auc_score

X, y = make_classification(n_samples=20_000, weights=[0.99], n_informative=5, random_state=0)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, stratify=y, random_state=0)
print("positive rate:", y.mean().round(4))

dummy = DummyClassifier(strategy="most_frequent").fit(X_tr, y_tr)
print("dummy accuracy:", round(accuracy_score(y_te, dummy.predict(X_te)), 4), "<- catches zero positives")

clf = LogisticRegression(max_iter=1000, class_weight="balanced").fit(X_tr, y_tr)
pred = clf.predict(X_te)
print(confusion_matrix(y_te, pred))
print(classification_report(y_te, pred, digits=3))
print("ROC-AUC:", round(roc_auc_score(y_te, clf.predict_proba(X_te)[:, 1]), 3))
