Paper summary: Learn Your Reference Model for Real Good Alignment

Trust Region alignment (TR-DPO, TR-IPO, TR-KTO) updates the reference policy during offline alignment training, which reduces over-optimisation.

  • Offline methods like DPO still over-optimise when the model drifts far from a fixed reference policy.
  • Periodically updating the reference, softly or by hard resets, lets the model move further while keeping quality.
