24:Tc7e,<h2 id="what-happened">What happened</h2>
<p>On 28 February 2024 <strong>BigCode</strong> released <strong>StarCoder2</strong>, the next generation of transparently trained open code LLMs, trained on <strong>The Stack v2</strong>, a new large, high-quality code dataset. All models, datasets, processing and training code were released.</p>
<h2 id="the-technical-details">The technical details</h2>
<p>From the Hugging Face post:</p>
<ul>
<li>three sizes: <strong>3B</strong> (trained by ServiceNow), <strong>7B</strong> (Hugging Face) and <strong>15B</strong> (NVIDIA, using NeMo on NVIDIA infrastructure)</li>
<li><strong>StarCoder2-15B:</strong> 4+ trillion tokens and <strong>600+ languages</strong>; the 3B and 7B models use 17 languages and 3+ and 3.5+ trillion tokens</li>
<li>architecture: <strong>Grouped Query Attention</strong>, a <strong>16,384-token</strong> context with <strong>4,096-token sliding-window attention</strong>, trained with the <strong>Fill-in-the-Middle</strong> objective</li>
<li>StarCoder2-15B matches <strong>33B+ models</strong> on many evaluations, and StarCoder2-3B matches the earlier StarCoder1-15B</li>
</ul>
